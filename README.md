Media Downloader — простая десктопная программа для Windows. Работает локально: ничего не отправляет на сторонние серверы, не показывает рекламу и не ограничивает количество загрузок. Внутри используется мощный движок [yt-dlp](https://github.com/yt-dlp/yt-dlp), поэтому поддерживаются сотни сайтов.

![Главное окно](docs/screenshots/01-format.png)

## ✨ Возможности

- 🎬 **Лучшее качество** — видео + аудио, автоматически склеенные в MP4
- 🎵 **Только аудио** — mp3, m4a, opus, wav с выбором битрейта
- 📼 **Только видео** — без звуковой дорожки
- 📚 **Плейлисты** — целиком или по диапазону номеров
- 🎯 **Таблица форматов** — выберите точное разрешение, кодек, FPS и размер
- 📋 **Очередь загрузок** — много ссылок разом, в 1–4 потока, с превью
- 🖼 **Превью** — обложка, канал и длительность до скачивания
- 🕘 **История загрузок** — последние файлы с превью и повтором в один клик
- 🔔 **Уведомления Windows** — сообщение о готовом файле, если окно свёрнуто
- 🎨 **Тёмная тема** — аккуратные карточки, единый акцент и понятные состояния
- ⚡ **Shorts** и обычные ролики — одинаково просто
- 📊 **Прогресс** — процент, скорость, оставшееся время, размер файла
- ⏸ **Пауза и продолжение** — загрузка докачивается с места остановки
- ⏹ **Остановка** с корректной отменой загрузки
- 🍪 **Cookies** — для возрастных и приватных видео
- 🔁 **Автоповтор** — до 3 попыток разными способами при сбоях
- 🗂 **Архив загрузок** — не качает повторно то, что уже скачано
- 🔄 **Обновление yt-dlp** — прямо из программы, в один клик
- ⌨️ **Горячие клавиши** и автоподстановка ссылки из буфера обмена
- 💾 **Запоминает настройки** между запусками (включая размер и положение окна)
- 📦 **Портативный `.exe`** — не требует установки Python

## 📥 Скачать

### Вариант 1. Готовый .exe (проще всего)

1. Откройте страницу [**Releases**](../../releases/latest)
2. Скачайте `Media-Downloader.exe`
3. Запустите — установка не нужна

> Windows может показать предупреждение SmartScreen («Неизвестный издатель»), потому что файл не подписан платным сертификатом. Нажмите **«Подробнее» → «Выполнить в любом случае»** — но сначала сверьте контрольную сумму из следующего раздела.

### Проверка скачанного файла

К каждому релизу приложен `SHA256SUMS.txt`. В нём — SHA-256 файла, который собрал GitHub Actions из исходников этого репозитория. Сравните:

```powershell
Get-FileHash .\Media-Downloader.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

Хэши должны совпасть. Если установлен [GitHub CLI](https://cli.github.com/), можно дополнительно проверить происхождение сборки:

```powershell
gh attestation verify .\Media-Downloader.exe --repo TTsanchez/media-downloader
```

Скачивайте `.exe` только со [страницы Releases](../../releases/latest) этого репозитория: чужие копии могут быть изменены.

### Вариант 2. Из исходников

Нужен [Python 3.10+](https://www.python.org/downloads/) (при установке отметьте **Add Python to PATH**).

```bat
git clone https://github.com/TTsanchez/media-downloader.git
cd media-downloader
start.bat
```

`start.bat` сам создаст окружение, установит зависимости и откроет программу.

## 🚀 Как пользоваться

1. **Вставьте ссылку** на видео, аудио или плейлист в поле сверху.
2. Нажмите **«Получить информацию»** — появятся название, обложка, канал и длительность.
3. На вкладке **«Формат»** выберите, что скачивать: лучшее качество, только видео или только аудио. Здесь же есть **таблица форматов** — можно выбрать конкретное разрешение, кодек и размер, — и **пресет качества** (1080p, 720p и т. д.), который просто ограничивает разрешение.
4. Нажмите **«Скачать»**. Прогресс виден внизу окна, а кнопка **«Журнал»** раскрывает подробный лог; **«Пауза»** останавливает загрузку так, что её можно продолжить с места остановки.
5. Готовый файл — в папке загрузок (кнопка **«Папка»**). По завершении появится окно с кнопкой **«Открыть папку»**, а если окно программы свёрнуто — системное уведомление Windows.

### 📋 Очередь загрузок

![Очередь загрузок](docs/screenshots/05-queue.png)

Вкладка **«Очередь»** нужна, чтобы скачать много ссылок сразу:

1. Вставьте ссылки (по одной в строке) или нажмите **«Из файла...»** / **«Вставить»**. Можно перетащить `.txt` со ссылками прямо на значок программы — очередь пополнится при запуске.
2. Выберите число потоков (1–4) и нажмите **«Добавить в очередь»**.
3. Нажмите **«Скачать всё»** — по каждой ссылке виден статус и процент. **«Пауза»** останавливает очередь, чтобы продолжить позже, **«Остановить»** отменяет её. Кнопки управления очередью всегда находятся в нижней панели и видны без прокрутки.

Очередь сохраняется между запусками: недокачанные ссылки вернутся в неё при следующем открытии программы.

### 🕘 История загрузок

![История загрузок](docs/screenshots/04-history.png)

Вкладка **«История»** показывает последние скачанные файлы: обложку, название, канал, длительность, формат и размер. Для каждой записи есть кнопки **«Повторить»**, **«Папка»** и **«Удалить»**; всю историю можно очистить одной кнопкой — сами файлы при этом остаются на диске.

История хранится только на этом компьютере, в `%LOCALAPPDATA%\Media-Downloader\history.json`, и вмещает до 300 записей.

### 🔔 Уведомления

Когда загрузка завершается, а окно программы неактивно, Windows показывает уведомление с названием файла. Отключить его можно в **«Настройки» → «Уведомления и превью»**.

### ⌨️ Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Enter` / `F5` | Получить информацию по ссылке |
| `Ctrl+D` | Начать загрузку |
| `Esc` | Остановить загрузку |

## 🗂 Архив загрузок

Включите **«Настройки» → «Архив загрузок» → «Пропускать уже скачанное»** — программа запомнит, что скачала, и при повторном запуске тех же ссылок или плейлиста не будет качать их заново. Список хранится в отдельном файле (путь можно изменить).

## 🧩 Требования

**Готовый `.exe` — это компактная сборка (~22 МБ).** Всё нужное она доустанавливает сама при первом запуске в `%LOCALAPPDATA%\Media-Downloader`; права администратора не нужны:

- yt-dlp, yt-dlp-ejs и плагин PO Token — из PyPI;
- FFmpeg и ffprobe — сборка с GitHub (общие библиотеки).

Первый запуск занимает 1–2 минуты: окно прогресса показывает, что скачивается. Дальше программа открывается сразу. Если места на диске мало или что-то удалили, компоненты можно восстановить в **«Настройки» → «Компоненты»**.

Тяжёлые компоненты (Deno, Node.js, Git и PO Token) ставятся по требованию кнопкой **«Установить всё»** — они нужны только для защищённых видео YouTube.

`build_exe.bat` собирает такую же компактную версию: FFmpeg и yt-dlp в `.exe` не вшиваются.

## 🍪 Cookies

Для обычных публичных видео cookies **не нужны** — программа скачивает их сразу. yt-dlp сам подбирает клиент YouTube: без логина он использует анонимный клиент (`visionos`), которому не нужны ни cookies, ни PO Token, ни JavaScript-рантайм.

Cookies понадобятся, только если YouTube требует «подтвердить, что вы не робот», а также для возрастных, приватных и привязанных к аккаунту видео.

**Способ 1 — напрямую из браузера.** «Настройки» → Cookies → выберите браузер. Список строится автоматически по установленным браузерам.

> **Важно про Chrome/Edge 127+.** Google перевёл cookies на app-bound encryption: ключ привязан к самому браузеру, и внешняя программа его не расшифрует. Поэтому такие браузеры помечены «нельзя (защита 127+)», и закрытие браузера **не помогает**. Из Firefox cookies читаются нормально.
>
> Если cookies не нужны — попробуйте скачать без них: для обычных видео это часто срабатывает.

**Способ 2 — файл cookies.txt (работает всегда).**
1. Установите в Chrome/Edge расширение **Cookie-Editor**
2. Откройте youtube.com под своим аккаунтом
3. Экспортируйте cookies в формате Netscape (`.txt`)
4. «Настройки» → Cookies → **«Загрузить»**

Данные cookies никуда не отправляются — они читаются локально и используются только для запросов к сайту.

## 🧱 Компоненты для работы с YouTube

С 2025 года YouTube требует **PO Token** и **JavaScript-челлендж**. Без них многие видео не открываются (`The page needs to be reloaded`). Программа устанавливает всё сама — вкладка **«Настройки» → «Компоненты»**.

| Компонент | Зачем | Как ставится |
|---|---|---|
| **yt-dlp** | Скачивание видео | Автоматически при первом запуске |
| **FFmpeg** | Склейка видео со звуком | Автоматически при первом запуске |
| **Deno** | Выполняет проверочный JS YouTube | Кнопка «Установить всё» |
| **Node.js и Git** | Нужны для сборки PO Token | Кнопка «Установить всё» |
| **PO Token сервер** | Генерирует токены доступа | Кнопка «Установить всё» |

Все компоненты ставятся портативно в `%LOCALAPPDATA%\Media-Downloader\tools` — без установщиков, winget и прав администратора. PO Token сервер — это локальная Node.js-программа [bgutil](https://github.com/Brainicism/bgutil-ytdlp-pot-provider). Она собирается один раз, запускается сама при старте программы на `127.0.0.1:4416` и останавливается при выходе. Файлы никуда не отправляются.

> Если эти компоненты не установлены, обычные видео часто всё равно скачиваются. Они обязательны для возрастных, приватных и защищённых видео.

## 🌐 Сеть и блокировка YouTube (VPN / прокси)

В России YouTube часто блокируется провайдером **по имени домена (SNI/DPI)**: интернет работает, `google.com` открывается, а YouTube — нет. Соединение обрывается ещё до шифрования, поэтому скачать видео не может **ни одна** локальная программа — проблема не в коде.

Проверить причину: «Настройки» → **Сеть и прокси** → **«Проверить сеть»**.

- YouTube доступен напрямую — программа скачает видео сама.
- Показана «блокировка по имени домена (SNI/DPI)» — нужен **VPN** или **прокси**.

Чтобы качать через прокси, впишите его адрес в поле «Прокси» (сохраняется в конфиге):

| Пример | Описание |
|---|---|
| `http://хост:порт` | HTTP/HTTPS-прокси |
| `socks5://хост:порт` | SOCKS5-прокси |
| `http://логин:пароль@хост:порт` | Прокси с авторизацией |

Пусто — прямое подключение. Локальный PO Token сервер (`127.0.0.1`) всегда идёт мимо прокси.

### Автоповтор при сбоях

Программа делает до **3 попыток** разными способами доступа к YouTube. При сетевых ошибках, `The page needs to be reloaded`, `No video formats found` она переключается на другой способ и повторяет, а не падает сразу.

## Диагностический отчёт

Если программа показывает ошибку, нажмите **«Сохранить отчёт»** в нижней панели. Полученный ZIP можно приложить к issue или прислать человеку, который помогает разобраться. Добавьте описание действий перед ошибкой.

Журналы автоматически сохраняются в `%LOCALAPPDATA%\Media-Downloader\logs`, в том числе после закрытия программы. Если окно не открылось, найдите файлы там; после следующего запуска экспорт также включает журналы предыдущих сеансов.

В отчёте есть версии приложения, Python, Windows и компонентов, идентификаторы загрузок, попытки и прогресс, traceback ошибок интерфейса и фоновых потоков, сообщения yt-dlp, коды выхода и последние сообщения внешних процессов. Поддерживаемые Python нативные сбои записываются отдельно через `faulthandler`. Сбой самого обновляющего скрипта также имеет свой журнал.

Обычный журнал ограничен 2 МиБ с тремя резервными файлами; между сеансами сохраняется до 20 файлов. Экспорт включает до 12 последних файлов и до 4 МиБ из каждого. Cookies, конфигурация, переменные окружения и скачанные файлы к отчёту не прикладываются. Заголовки авторизации, известные пароли и cookie-значения, параметры URL и домашний путь пользователя маскируются перед записью обычных журналов и при экспорте всех журналов, включая нативные трассировки. Автоматической отправки отчётов нет.

Перехватить отключение питания, принудительное завершение процесса или сбой до запуска Python невозможно; в этих случаях остаются последние записанные события. При недоступности основной папки используется временная, а при невозможности записи на диск — ограниченный журнал в памяти, который нужно экспортировать до закрытия.

## 🛠 Если что-то не работает

| Сообщение | Причина и решение |
|---|---|
| `Connection reset` / `Connection aborted` / таймаут TLS | Сеть блокирует YouTube (SNI/DPI). Включите VPN или укажите прокси — «Настройки» → Сеть и прокси |
| `Failed to decrypt with DPAPI` | Защита cookies Chrome/Edge 127+. Нужен `cookies.txt` из Cookie-Editor |
| `Could not copy cookie database` | Браузер открыт — закройте его полностью |
| `Sign in to confirm you're not a bot` | Нужны cookies. Если не помогло — IP временно заблокирован YouTube (обычно проходит за несколько часов) |
| `The page needs to be reloaded` | Нет PO Token — установите Deno и PO Token во вкладке «Настройки» |
| `Confirm your age` | Возрастное ограничение — нужны cookies |
| `This video is private` | Нужен доступ по ссылке для приглашённых |
| `Unsupported URL` | Сайт не поддерживается или ссылка неверная. Проверьте список поддерживаемых сайтов yt-dlp |
| `Video unavailable` | Видео удалено или недоступно в вашем регионе |

## ⬆️ Обновление

Сайты периодически меняют внутреннюю защиту, поэтому движок yt-dlp стоит держать свежим. В программе есть всё для этого: **«Настройки» → «Обновление yt-dlp»**.

- **«Проверить обновления»** — показывает установленную и доступную версию.
- **«Обновить yt-dlp»** — скачивает свежую версию в папку компонентов. Работает и в собранном `.exe`; переустанавливать программу не нужно. Изменения применятся после перезапуска.

При старте программа тихо проверяет наличие новой версии и пишет об этом в журнал.

Вручную (из исходников):

```bat
py -m pip install -U yt-dlp
```

## 👨‍💻 Разработка

```bat
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Сборка одного `.exe` (результат в `dist\Media-Downloader.exe`):

```bat
build_exe.bat
```

После сборки скрипт сам запускает самопроверку `--selftest`: она проверяет версию, файлы, импорт модулей, папку компонентов и Tk, а отчёт пишет в `%LOCALAPPDATA%\Media-Downloader\selftest.txt`.

Структура проекта:

| Файл | Назначение |
|---|---|
| `main.py` | Интерфейс (tkinter + ttkbootstrap) |
| `bootstrap.py` | Порядок установки и окно первого запуска |
| `components.py` | Установка и проверка yt-dlp, FFmpeg, Deno, Node.js, Git, PO Token |
| `selftest.py` | Самопроверка собранного `.exe` без сети |
| `net.py` | Загрузки с докачкой, повторами и проверкой SHA-256 |
| `downloader.py` | Обёртка над yt-dlp, форматы, автоповтор |
| `utils.py` | Пути, FFmpeg, браузеры, cookies, проверка сети |
