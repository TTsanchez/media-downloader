# Журнал изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [1.2.0] — 2026-10-28

### Добавлено

- Постоянный диагностический журнал с ротацией, идентификаторами сеансов и загрузок, traceback ошибок интерфейса и фоновых потоков, выводом yt-dlp и внешних процессов.
- Кнопка «Сохранить отчёт»: ZIP с журналами текущего и предыдущих запусков и версиями компонентов. Секреты маскируются; cookies, конфиг и окружение не прикладываются.
- Ранняя обработка ошибок запуска, нативные трассировки через `faulthandler` и журнал скрипта автообновления.
- Обновление yt-dlp из программы: кнопки «Проверить обновления» и «Обновить yt-dlp», тихая проверка при старте и показ версии в статус-баре
- Архив загрузок: режим «пропускать уже скачанное» (не качать повторно те же ссылки/плейлисты)
- Автоподстановка ссылки из буфера обмена, когда поле пустое
- Горячие клавиши: `F5`/`Enter` — информация, `Ctrl+D` — скачать, `Esc` — остановить, `Ctrl+O` — папка загрузок
- Запоминание размера и положения окна
- Таблица доступных форматов: разрешение, кодек, FPS и размер; выбор конкретного формата для загрузки
- Очередь / пакетная загрузка: список ссылок, параллельная загрузка (1–4 потока), добавление из файла и из буфера обмена, прогресс по каждой ссылке, остановка

### Изменено

- Готовый `.exe` стал компактным (~22 МБ): FFmpeg, yt-dlp и плагин PO Token больше не вшиваются, а доустанавливаются при первом запуске в `%LOCALAPPDATA%\Media-Downloader\tools`. Прогресс показывается в отдельном окне; права администратора не нужны.
- yt-dlp, yt-dlp-ejs и bgutil-плагин ставятся из wheel-архивов PyPI, FFmpeg — статической сборкой с GitHub, без pip и установщиков.
- Deno, Node.js и Git ставятся портативными архивами в папку компонентов, PO Token собирается из них локально. Winget и права администратора больше не требуются.
- В настройках появился раздел «Компоненты»: статус yt-dlp, FFmpeg, Deno, Node.js, Git и PO Token, кнопки «Проверить», «Установить всё», «Восстановить FFmpeg» и «Открыть папку».
- Обновление yt-dlp работает и в собранном `.exe` — переустанавливать программу не нужно.
- Сборка проверяет кодировку исходников и падает при BOM, не-UTF-8 или кракозябрах; локальная сборка запускается с `PYTHONUTF8=1`.
- Обычные публичные видео качаются **без cookies**: первая попытка больше не задаёт `player_client` и PO Token, а отдаёт выбор клиента самому yt-dlp (он идёт анонимным клиентом `visionos`, которому не нужны ни cookies, ни PO Token, ни JS-рантайм). Запасные попытки: `visionos`+`android_vr`, затем `mweb`+`tv`
- Cookies стали строго опциональными — только для возрастных/приватных видео и «подтвердите, что вы не робот»

### Исправлено

- Устранены кракозябры в русском тексте готового `.exe`: релизная сборка штампует версию из тега и проверяет кодировку до упаковки.
- Убрано ложное предложение обновиться, когда версия в `version.txt` не совпадала с тегом релиза.
- Исправлен выбор Windows-архива FFmpeg. Восстановление проверяет контрольную сумму и записывает компоненты в пользовательскую папку без прав администратора.
- Обновление `.exe`: исправлены запуск установщика, чтение версии из PyInstaller и кодировка путей с кириллицей. Скачивание выполняется в фоне с сохранением через временный файл.
- Обновления yt-dlp не запускаются одновременно с загрузками и очередью.
- Результаты фоновых операций передаются в основной поток Tk; события прогресса содержат независимые снимки состояния.
- Очередь корректно дожидается рабочих потоков, сохраняет итоговые статусы и отклоняет повторные и некорректные ссылки.
- Проверяется диапазон плейлиста и число одновременных загрузок; режим всего плейлиста игнорирует ранее выбранное начало.
- Режим «Только видео» использует исключительно видеодорожку. При отключении ограничения имён сохраняется полное название.
- Ошибки отдельных элементов плейлиста больше не отображаются как успешная загрузка.
- После изменения ссылки сбрасывается выбранный формат; устаревшая информация не подменяет данные новой ссылки.
- Запуск локального сервера токенов синхронизирован; при выходе завершается только запущенный программой процесс.
- Нижние действия закреплены при изменении размера окна, улучшены контрастность и отступы, ограничен размер журнала.
- Добавлены регрессионные тесты, проверки окна Tk и загрузка через настоящий yt-dlp с локального HTTP-сервера.
- Настройки больше не перезатираются значениями по умолчанию при запуске (конфиг сохраняется после их загрузки)
- Режим «Только видео» скачивает видео без звуковой дорожки (раньше подмешивался звук)
- Убрано вводящее в заблуждение предупреждение «без cookies YouTube ограничивает качество 360p» — для обычных видео это не так

## [1.0.0] — 2026-10-14

Первый публичный релиз.

### Добавлено

- Скачивание видео, аудио и плейлистов: YouTube и сотни других сайтов (VK, RuTube и т. д.)
- Режимы: лучшее качество (MP4), только видео, только аудио (mp3/m4a/opus/wav)
- Выбор диапазона для плейлистов
- Прогресс загрузки: процент, скорость, ETA, размер
- Корректная остановка загрузки
- Чтение cookies из браузера и из файла `cookies.txt`
- Установка Deno и PO Token сервера в один клик
- Проверка сети с определением блокировки по SNI/DPI
- Поддержка прокси (http/https/socks5)
- Автоповтор до 3 раз разными стратегиями при сбоях
- Запоминание настроек между запусками
- Сборка в портативный `.exe`
