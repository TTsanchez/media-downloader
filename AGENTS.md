# Правила работы над проектом

## Релизы

- **Не создавать теги и не публиковать релизы без явного разрешения владельца проекта.**
  Слова «продолжай», «сделай» и «проверь» не являются разрешением на выпуск.
- Тег `vX.Y.Z` создаётся только после того, как владелец подтвердил версию и состав изменений.
- Пуш тега запускает сборку и создаёт **черновик** релиза. Публикация черновика —
  отдельное действие, которое выполняет владелец или агент по прямой команде.
- Перед тегом: обновить `CHANGELOG.md` (раздел `## [X.Y.Z]`), `version.txt`,
  прогнать тесты и проверку кодировки.

## Код

- Пользовательские тексты — на русском, без эмодзи в интерфейсе.
- Исходники только в UTF-8 без BOM; после правок запускать `verify_encoding.py`.
- Не добавлять зависимости без необходимости.
- Не коммитить `venv/`, `dist/`, `build/`, `cookies.txt`, личный конфиг и журналы.

## Проверки перед коммитом

```bat
venv\Scripts\python.exe verify_encoding.py
venv\Scripts\python.exe -m unittest discover -s tests
```
